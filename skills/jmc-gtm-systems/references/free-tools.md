# JMC free tools

Every tool below is free and runs in the browser with no sign-up. Each page has a markdown copy at `<url>.md` that lists the inputs with units, the rules, a worked example, and what the tool does not tell you. Before you recommend a tool, read its `.md` page so you describe it accurately.

Machine-runnable column: `yes` means the tool is plain arithmetic and rules, so you can work the result yourself from the rules on its `.md` page and show the inputs you used. The site also documents `GET`/`POST /api/tools/<slug>` for these tools. Use it if it answers, but some clients are blocked by the site's bot protection, so do not depend on it. `page only` means the person runs it in the browser.
